# Claude Memory Export — Octopus Product Mechanisms

## Summary

The export records Octo as an AI-native collaboration OS organized around Open, Context, Taste, and Orchestration. Its core product mechanisms are Items, append-only review signals, FileSpace and task Context, and Monitor checkpoints.

<div class="zh-trans">该导出将 Octo 记录为以 Open、Context、Taste 和 Orchestration 为核心的 AI-native 协作 OS。其核心产品机制包括 Item、append-only 品鉴信号、FileSpace 与任务级 Context，以及 Monitor 检查点。</div>

## Core points

- An Item is a structured top-level work unit, while Thread and Channel can contain both Items and messages.
- Review is mandatory final acceptance; Monitor is an optional process-intervention checkpoint that becomes important for high-risk work.
- FileSpace is durable and human-managed; Context is a temporary task package assembled by Agents and curated back into FileSpace.

<div class="zh-trans">核心要点：Item 是结构化的顶层工作单元，Thread 与 Channel 都可承载 Item 和消息；品鉴是必经的最终验收，Monitor 是可选的过程介入检查点，在高风险工作中尤为重要；FileSpace 是持久且由人管理的仓库，Context 是由 Agent 组装、并经筛选回流至 FileSpace 的临时任务包。</div>
